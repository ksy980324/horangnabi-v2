### 홈 화면 정리 및 LAN 여행 생성 오류 수정 (2026-11-05)

- 새 여행 날짜 기본값을 오늘로 채우고 시작일을 종료일 뒤로 변경하면 종료일도 맞춘다. 날짜는 사용자가 변경 가능하며 기존 기간 검증과 편집 중 일정 보호는 유지한다.

### 선택 도시와 지도·장소 검색 연결 (2026-11-05)

- 일정 핀이 있으면 기존처럼 해당 핀 범위를 표시하고, 핀이 없으면 선택 도시로 이동한다. 여행 ID도 지도 범위 변경 기준에 포함하여 같은 날짜의 다른 여행을 열어도 올바른 도시로 이동한다. 마지막 좌표 핀이 사라져도 도시로 돌아가도록 했다. Google/무료 지도 모두 적용하며 지도 인스턴스를 재생성하지 않는다.

### 고정 지도와 스크롤 연동 (2026-11-05)
- 모바일에서도 일정을 스크롤할 때 지도를 상단에 고정하고 지도 높이를 화면 높이에 맞게 제한했다. 가로 모드의 낮은 화면에서는 지도 영역을 더 줄인다. 데스크톱의 기존 고정 배치도 유지한다.

- 지도 높이를 측정하여 핀 선택 후 목표 카드가 지도 아래에 보이도록 스크롤 여백을 적용했다. 새 지도 인스턴스나 별도 API 요청은 추가하지 않는다.
- TypeScript 검사·단위 테스트 11개·Vite 빌드 통과. 새 테스트는 지도 뒤에 가려진 카드 제외, 스크롤 방향, 긴 상세 카드, 낮은 화면, 마지막 카드 및 화면 밖 카드 처리를 검증한다.
- 연결된 Chrome의 모바일 화면(실측 너비 400px)에서 Google 지도 상단 고정, 스크롤에 따른 4번 장소 이동, 3번 카드 선택 시 이동, 3번 핀의 키보드 선택 후 해당 카드가 지도 아래에 노출되는 것을 확인했다. 지도 상단 8px, 카드 상단은 지도 하단보다 아래에 있었다. 가로 넘침 없음. 실제 휴대폰 터치 및 넓은 데스크톱 배치는 이번에 별도 검증하지 않았다.
- 키보드로 핀에 포커스를 옮길 때 브라우저 자동 스크롤이 다른 카드를 선택하는 문제를 브라우저 확인 중 발견하여 수정하고 재확인했다. 임시 브라우저 화면 크기 설정은 복원했다.

## Google 지도 공유 링크 저장

- 짧은 공유 링크를 확인하는 Cloudflare Worker와 일정·보관함 자동 입력을 추가했다. `MAPS_LINK_RESOLVER_URL`을 설정한 Pages 빌드에서 활성화된다. Worker 배포와 공개 사이트 동작 확인은 Cloudflare 계정과 배포 URL이 필요하다.

- Google 지도 장소 페이지 주소에 더해 검색 링크의 경로, `query`, `q`에도 장소 이름이 있으면 자동 입력한다. 지도 화면 중심을 나타내는 `@위도,경도`는 핀으로 사용하지 않는다.

- 장소 이름이 있는 Google 지도 전체 주소나 공유 텍스트를 붙여넣으면 이름을 자동 입력한다. 링크에 검색 좌표가 명시된 경우에만 핀도 자동 입력하며, 짧은 링크만 있는 경우 이름을 직접 입력하거나 전체 주소를 붙여넣을 수 있다.

- 일정과 장소 보관함에 Google 지도 공유 링크를 저장하고 카드 상세에서 열 수 있게 했다. 링크는 기존 백업과 공유 여행 데이터에 포함된다. 지도 핀이 필요하면 위치를 별도로 지정한다.

## 알려진 제약
- localStorage는 각 브라우저/주소에 독립적이다. 기기 간 동기화·데이터 합치기는 지원하지 않는다.
- 공용 지도 및 Photon 데모 검색 서버는 인터넷과 제공자의 가용성에 의존한다. 자동 재시도·자동완성 요청은 없다. 검색 제한은 브라우저 세션 단위이며 두 기기를 중앙에서 조율하지 않는다. 2초 이상의 간격과 소규모 개인 사용을 전제로 한다.
- 한국어 지명/장소 검색 품질은 원본 지도 데이터에 따라 다르다. 영문/현지어로 검색할 수 있다.
- 검색 캐시는 메모리에만 보관하며 새로고침 시 초기화된다.
- 여행 기간은 최대 366일. 기존 일정이 제외되는 기간 수정은 먼저 일정 이동/삭제가 필요하다.
- 이동 경로, 거리·이동 시간 계산, 자동 순서 최적화, 이미지 업로드, 여행 공유는 없다.
- 시간에 따른 자동 정렬은 하지 않는다. 카드 순서가 핀 번호의 기준이다.
- 실제 지도 및 모바일 UI 검증 후 배포하는 것이 다음 필수 단계다.
